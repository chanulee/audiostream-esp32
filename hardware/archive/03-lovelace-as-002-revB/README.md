# LOVELACE / AS-002 rev B (보관, 버전 기록 03)

ESP32-WROVER-E-N8R8 + PCM5102A, **35 × 50 mm, 4층**. S3에서 WROVER로 바꿔 Bluetooth A2DP를 넣은 첫 설계입니다. 고정 홀 M2 × 2, BOOT·RESET 버튼, PCM12 전원 스위치, CUI SJ1-3523N(THT) AUX 잭을 썼습니다.

같은 폴더(`hardware/lovelace-as-002`)에서 rev C로 바로 고쳐 나가느라 원본(스크립트, KiCad 파일)은 남지 않았습니다. 남은 것은 당시 검토용으로 뽑은 구리층 이미지 두 장뿐입니다(`copper-F_Cu.png`, `copper-B_Cu.png`). 주문하지 않았습니다.
