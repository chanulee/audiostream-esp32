# AS-003 rev A 배선·펌웨어 검토 — 2026-10-16

보드 파일(`lovelace-as-003.kicad_pcb`)을 KiCad Python으로 직접 읽어 수치로 검사했습니다. 대상은 배선, via, 평면, 패드, 부품 외곽입니다. 펌웨어는 소스와 `sdkconfig.lovelace-as-003`을 읽었습니다. 넷리스트 검토는 [REVIEW_NETLIST.md](REVIEW_NETLIST.md)에 있습니다. 실물 측정은 없습니다.

## 발견 사항

### 주문 전에 고칠 것

1. **[Major, 수정함] 상단 SMD 패드 안에 via가 4개 있었습니다.** 모두 KiCadRoutingTools가 만든 것입니다. 메우지 않은 via가 마스크 개구부 안에 있으면 tenting이 적용되지 않습니다. 그래서 리플로 때 땜납이 구멍으로 빠져 접합이 약해지거나, 0402가 한쪽만 붙어 서는 툼스톤이 생길 수 있습니다. KiCad DRC는 같은 넷의 via와 패드를 검사하지 않아 통과했습니다.

   | 위치 | 패드 | via | 접합이 실패하면 |
   |---|---|---|---|
   | R17 패드 1 (POWER_EN) | 0402, 0.64 × 0.54mm | Ø0.54 / 드릴 0.29, 패드를 거의 덮음 | UVLO 분압이 사라져 EN이 VBUS 전압을 그대로 받음. UVLO 기능 없음 |
   | R10 패드 2 (XSMT) | 0402, 0.54 × 0.64mm | Ø0.6 / 0.3, 패드보다 큼 | XSMT 풀다운이 없어짐. 부팅 중 뮤트가 보장되지 않아 전원 투입 팝 가능 |
   | U4 1번 핀 (+5V_DAC, LDO 입력) | SOT-23-5, 1.32 × 0.6mm | Ø0.6 / 0.3, 패드 중앙 | LDO 입력 접합 불량 → DAC 전원 없음 → 소리 없음 |
   | U1 34번 핀 (UART_RX) | 모듈 패드 1.5 × 0.9mm | Ø0.6 / 0.3, 패드 가장자리 | 모듈 납땜 불량 → 플래시·로그 불가(바닥 RX 패드로 우회 가능) |

   via 구리는 패드와 붙어 있으므로 전기 연결 자체는 유지됩니다. 문제는 부품 납땜입니다. **수정 내용:**
   - **검사:** `audit_pcb.py`에 상단 SMD 패드에 닿는 via 검사를 넣었습니다. 패드 가장자리에 걸친 via까지 잡도록 하자 6개가 더 나왔습니다(U6.1·U6.2, C10.1, C8.1, R13.2, U7.6). 이 검사는 실패하면 빌드를 멈춥니다.
   - **라우터:** via를 놓는 전원·신호 단계에 `--same-net-pad-clearance 0.1`을 줬습니다.
   - **OVLO·ILIM:** U6 가운데 핀인 이 두 넷은 라우터가 길을 못 찾아 `build_pcb.py`에서 손으로 그렸습니다. OVLO via는 패드에서 0.1mm 이상 떨어뜨렸고, ILIM은 이전과 같은 F.Cu 경로입니다.
   - **테스트 패드 via:** `finish_pcb.py`가 바닥 테스트 패드용 via를 상단 패드에서 띄우도록 했습니다(U7.6이 여기서 나왔음).
   - **오디오 배선 잠금:** 전원 단계가 막히면 DAC_L/R을 뜯어 B.Cu로 옮기는 일이 생겨서, 오디오 단계 직후 오디오 배선을 잠갔습니다.

   결과는 DRC 0, 미연결 0, 패드에 닿는 via 0개입니다. 오디오 넷은 F.Cu 전용이고 길이도 이전과 같습니다(DAC_L 15.0, DAC_R 17.2, LINE_L 14.7, LINE_R 24.3mm). 바닥 테스트 패드의 via는 조립하지 않는 면이라 검사에서 뺐습니다.

2. **[Major, 주문 설정] 보드 밖으로 나가는 부품 때문에 JLC 조립 레일 방향이 정해집니다.** 위쪽으로는 U1 모듈 안테나가 6.2mm, 아래쪽으로는 J2가 2.5mm, J1이 0.5mm 나갑니다. 조립 라인 레일(공정 가장자리)은 왼쪽·오른쪽에만 붙일 수 있습니다. 주문할 때 레일 위치를 지정하거나 JLC 엔지니어 확인을 요청해야 합니다. 위아래에 레일을 붙이면 부품과 겹칩니다. BRINGUP.md 1절에 추가했습니다.

### 첫 보드에서 확인할 것

3. **[Medium] USB 케이블 GND를 통한 잡음.** Wi-Fi 송신 펄스(약 0.3A)가 USB 케이블의 GND 저항(약 0.1Ω)을 지나면 보드 GND가 수십 mV 흔들립니다. 접지된 앰프와 PC USB를 동시에 쓰면 이 전압이 라인 출력에 "지직" 소리로 섞일 수 있습니다. USB 전원 오디오 기기에서 흔한 증상입니다. 절연형 휴대폰 충전기에서는 루프가 생기지 않습니다. BRINGUP.md 5절에 비교 항목을 추가했습니다. 문제가 되면 충전기 사용을 권장하거나 그라운드 루프 아이솔레이터로 대응합니다. 다음 rev에서 바꿀 회로는 아닙니다.

### 다음 rev에서 개선할 것

4. **[Minor] 버크 입력 루프.** C4(입력 10µF)가 U3 VIN·PGND 핀에서 약 3mm 떨어져 있고, 루프는 약 3 × 2mm입니다. 동작에는 문제가 없지만 2.25MHz 스위칭 잡음 방사를 줄이려면 C4를 U3 1·2번 핀 바로 옆에 붙입니다.
5. **[Minor, 펌웨어] 버튼을 누른 채 소프트웨어 리셋.** OTA·설정 저장 뒤 재시작하는 순간 버튼이 눌려 있으면 GPIO0 스트랩 때문에 다운로드 모드로 들어갑니다. USB를 다시 꽂으면 복구됩니다. 사용 설명에 적으면 충분합니다.
