## AS-006으로 올린 이유

AS-005는 KiCad 기본 풋프린트의 패드 위치와 길이를 그대로 썼습니다. Shou Han PJ-320D 도면의 "P.C.B LAYOUT"과 다시 대조해 보니, 플러그 축 방향 위치(패드 간격 3.0 / 4.0 / 1.1mm)는 0.1mm 이내로 맞았습니다. 하지만 축에서 패드까지의 거리가 달랐습니다.

| | 도면 | AS-005 | AS-006 |
|---|---|---|---|
| 축에서 패드가 덮는 범위 | 3.05–4.65mm (몸체 폭 6.1mm 바깥) | 2.0–4.5mm | 2.85–4.85mm |
| 패드 중심 / 길이 | 3.85 / 1.6mm | 3.25 / 2.5mm | 3.85 / 2.0mm |

AS-005 패드는 1mm가 몸체 아래로 들어가고, 바깥 끝은 도면보다 0.15mm 짧았습니다. 단자 끝을 덮지 못하면 필렛이 생기지 않습니다. 플러그를 꽂고 뺄 때 받는 힘이 이 접합부에 걸리므로 패드를 옮겼습니다.

옮긴 김에 같은 대조에서 찾은 CPL 문제도 고쳤습니다. `jlc_check.py`는 J2의 CPL 좌표를 패드 평균으로 맞추고 있었습니다. JLC 풋프린트와 패드 위치가 달라서, AS-005에서는 JLC 위치 결정 핀이 우리 홀에서 0.125mm 어긋나 있었습니다. 핀 Ø0.75mm가 홀 Ø1.0mm에 들어가므로 여유는 0.125mm뿐입니다. AS-006부터는 J2를 핀 기준으로 놓고 어긋남(0.000mm)을 검사합니다.
