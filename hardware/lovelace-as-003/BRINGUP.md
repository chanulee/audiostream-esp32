# AS-003 rev A 주문과 첫 보드 확인 절차

아직 실물로 확인한 항목은 없습니다. 아래 값은 데이터시트 기준 예상치이며, 측정값을 옆에 적어 두면 REVIEW.md의 미확인 항목을 하나씩 지울 수 있습니다.

## 1. JLCPCB 주문

1. `./make_board.sh`를 실행합니다. 끝까지 통과하면 `lovelace-as-003-revA-release.zip`(Gerber, drill), `bom.csv`, `cpl.csv`가 최신입니다. DRC·ERC 위반, JLC 부품 대조 실패, 감사 실패가 있으면 스크립트가 중간에 멈춥니다.
2. PCB: 4층, 1.6mm, 37 × 41mm. 임피던스 제어는 필요 없습니다(USB 2.0 Full Speed와 I2S 몇 mm).
3. PCBA: 윗면만 조립합니다. 바닥면에는 부품이 없고, 테스트 패드 11개만 있습니다(BOM·CPL에 없음).
4. **배치 미리보기에서 방향을 꼭 확인하세요.** `cpl.csv`는 `jlc_check.py`가 JLC 풋프린트 기준으로 회전과 원점을 다시 계산한 값입니다. KiCad 값을 그대로 쓰면 다음 부품이 돌아갑니다.

   | 부품 | KiCad 회전 | CPL(JLC) 회전 | 확인할 것 |
   |---|---:|---:|---|
   | U2 PCM5102A | 180 | 90 | 1번 핀 점이 오른쪽 아래(C12 쪽) |
   | U4 TPS7A2033 | 0 | 180 | 1번 핀(IN)이 C8 쪽 위 |
   | U5 USBLC6 | 0 | 270 | 1번 핀이 왼쪽 위 |
   | U7 CH340N | 0 | 270 | 1번 핀이 왼쪽 위(U5 쪽) |
   | C25 220µF 탄탈 | 90 | 270 | + 표시(띠)가 아래쪽(DAC 쪽) |
   | D5 RB551V | 270 | 270 | 캐소드 띠가 위쪽(5VD 쪽) |
   | D4 LED | 0 | 0 | 캐소드가 왼쪽(모듈 쪽) |

   `renders/latest/assembly-top.png`의 빨간 점이 1번 핀, K는 캐소드, +는 탄탈의 +입니다. 미리보기와 하나라도 다르면 주문 화면에서 회전을 고치거나 JLC 엔지니어 확인을 요청하세요.
5. Extended 부품은 19종입니다(종류마다 로딩 수수료). 재고는 2026-10-15 기준 모두 100개 이상입니다(`reports/jlc.json`).

## 2. 도착 후, 전원 넣기 전

- 육안 확인: U2(TSSOP-20) 핀 사이 브리지, U6(QFN 2 × 2mm)와 U3(WSON)의 측면 필렛, C25·D5·D4 방향.
- 바닥 테스트 패드 사이 저항을 멀티미터로 잽니다. 0Ω 근처면 전원을 넣지 마세요.

  | 패드 | 정상 예상 |
  |---|---|
  | VBUS–GND | 수백 kΩ 이상(분압 저항 383k+100k, 255k+100k) |
  | 5V–GND, 5VD–GND | 수 kΩ 이상 (5VD는 탄탈 충전으로 천천히 올라감) |
  | 3V3–GND, 3V3A–GND | 수백 Ω 이상 |

## 3. 첫 전원

- 가능하면 전류계가 있는 USB 미터나 전류 제한 0.3A의 5V 전원으로 시작합니다. eFuse가 0.56–0.75A에서 제한하지만 첫 투입은 낮게 잡는 편이 안전합니다.
- 바닥 패드에서 측정합니다.

  | 패드 | 예상 |
  |---|---|
  | VBUS | 입력 그대로(4.75–5.25V) |
  | 5V | VBUS보다 수십 mV 낮음 |
  | 5VD | 5V − 0.3V 정도(쇼트키) |
  | 3V3 | 3.3V ±3% |
  | 3V3A | 3.3V ±1% |
  | EN | 3.3V(10k/1µF로 약 10ms 뒤) |
  | IO0 | 3.3V, 버튼을 누르면 0V |

- 대기 전류는 펌웨어 없이 약 50–100mA로 예상합니다. 300mA를 넘으면 바로 분리하세요.

## 4. 펌웨어

1. 버튼(IO0)을 누른 채 USB를 꽂고 놓습니다. CH340N에 DTR이 없어서 자동 다운로드 모드가 없습니다.
2. 컴퓨터에 CH340 USB 시리얼이 보여야 합니다. 안 보이면 USB D+/D−·USBLC6·CH340N 쪽을 봅니다(바닥 TX/RX 패드로 외부 USB-UART를 대신 연결할 수 있습니다).
3. 플래시합니다.

   ```sh
   export PLATFORMIO_CORE_DIR="$PWD/work/platformio"
   .venv/bin/pio run -d firmware -e lovelace-as-003 -t upload
   .venv/bin/pio run -d firmware -e lovelace-as-003 -t uploadfs
   ```

   펌웨어는 0.3.0 이상, 환경은 `lovelace-as-003`이어야 합니다. `CONFIG_MUTE_GPIO=22`가 들어가기 때문입니다. **이 값이 없는 펌웨어(0.2.x, 옛 `lovelace-as-002` 환경)로는 DAC가 뮤트된 채 남아 소리가 나지 않습니다**(XSMT 풀다운). 웹 UI 정보 화면에서 펌웨어 버전을 확인할 수 있습니다.
4. USB를 다시 꽂고(버튼 없이) 115200bps 로그에서 PSRAM 8MB, 플래시 8MB, `Mute GPIO 22 initialized`, `I2S initialized`를 확인합니다. 상태 LED가 켜져야 합니다.

## 5. 기능

- Wi-Fi: `LOVELACE-Setup` AP에 접속해 집 Wi-Fi를 설정합니다.
- 소리: AirPlay로 **좌/우 채널 테스트 음원**을 재생합니다. 왼쪽이 Tip(L), 오른쪽이 Ring(R)으로 나와야 합니다. 이번에 고친 AUX 잭 배정을 확인하는 단계입니다. 재생 중 R10 패드(XSMT)는 3.3V여야 합니다.
- Bluetooth: 버튼 3초 → 휴대폰에서 페어링 → A2DP 재생. 48kHz 소스로 바뀔 때 팝이 없는지 들어 봅니다.
- Spotify Connect: 앱에서 장치 선택 → 재생.

## 6. 팝과 보호 동작

- 이어폰 대신 앰프 입력을 낮은 볼륨으로 연결하고 확인합니다. ① 전원 투입, ② 재생 중 USB 분리, ③ 소스 전환, ④ OTA·설정 저장 뒤 재부팅. 재생 중 USB 분리 대책(D5/C25 홀드업)은 계산상 5–10ms를 버텨야 합니다. 오실로스코프가 있으면 5VD와 라인 출력을 함께 잡아 보세요.
- (선택) 가변 전원: 5.5V 동작, 5.9–6.0V에서 차단(OVLO 5.63–6.00V), 4.1–4.4V 아래에서 꺼짐(UVLO).
- (선택) 케이스에 넣고 Wi-Fi RSSI와 A2DP + Wi-Fi 동시 사용 시 끊김을 확인합니다.

## 바닥 테스트 패드

`renders/latest/bare-bottom.png`에 이름과 함께 보입니다. VBUS, 5V, 5VD(+5V_DAC), 3V3(+3V3_D), 3V3A, GND, GND2, TX, RX(ESP32 쪽 UART0), EN(GND에 대면 리셋), IO0(GND에 대면 다운로드 모드 진입 조건)입니다. XSMT는 바닥에 자리가 없어 윗면 R10 패드에서 잽니다.
